# Slack Redirect Tab Closer

Chrome で Slack のリンク（`https://example.slack.com/archives/...` など）を踏むと、
デスクトップアプリが起動したあとに「◯◯ を立ち上げています」という中継タブが残る。
これを自動で閉じるだけの Chrome 拡張機能。

## 前提

Chrome の許可ダイアログで
**「example.slack.com でのこのタイプのリンクは常に関連付けられたアプリで開く」** に
チェックを入れておくこと。

未チェックのままだとリンクを踏むたびにダイアログが出るため、
拡張機能がタブを閉じた瞬間にダイアログごと消えて **Slack が起動しなくなる**。

## インストール

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を ON にする
3. 「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選ぶ

シンボリックリンクは不要。このフォルダを直接読み込む。

## 挙動

- `*.slack.com`（`app.slack.com` を除く）の中継ページを読み込んだタブが対象。
- そのタブが **直前に新規作成されたタブ** のときだけ閉じる。もともと開いていたタブを巻き込まない。
- 読み込み完了から 2 秒待ってから閉じる。アプリの起動を待つため。
- 閉じる直前に URL を再確認する。「このリンクをブラウザで開く」を押していた場合は閉じない。
- ウィンドウ内の最後の 1 タブは閉じない。Chrome ごと終了してしまうため。

## 調整するとき

`background.js` の先頭の定数をいじる。

- `CLOSE_DELAY_MS` : アプリ起動を待つ時間。タブが消えるのが早すぎるなら伸ばす。
- `REDIRECT_URL` : 対象にする URL のパターン。閉じないパスがあれば追加する。
