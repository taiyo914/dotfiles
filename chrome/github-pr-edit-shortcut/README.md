## 使い方

Github の PR の description 画面で、「E」を押すと description の編集画面に入る。また Esc で編集をキャンセルする。

編集画面では、「E」を押す前に読んでいた場所にカーソルを置き、その行を「E」を押す前と同じ画面の高さに表示する。読んでいた場所は次の順で決める。

1. 本文の文字を選んでいれば、その文字（編集画面でも同じ文字を選んだ状態にする）
2. マウスが本文の上にあれば、マウスのある場所
3. どちらでもなければ、画面の真ん中の高さにある文字

また、次の操作は Github がもともと持っているショートカットで、合わせて使うとよい。

- cmd Enter で description を更新
- cmd shift P で Preview と Edit を切り替える
