# macOS

macOS の設定のうち、ファイルを置くだけでは反映できないものをここに記録する。各マシンでは、この README を見ながら手動で設定する。

## 1. フォルダ構成

| パス | 中身 |
| - | - |
| `DefaultKeyBinding.dict` | macOS の Emacs 風キーバインドを無効にする設定。`~/Library/KeyBindings/DefaultKeyBinding.dict` からシンボリックリンクを張っている |
| `README.md` | 手動で設定する項目の一覧（このファイル） |

## 2. 手動で設定する項目

### 2-1. アプリのショートカット

アプリのメニューバーの項目にショートカットを割り当てる。

| アプリ | メニュータイトル | キー |
| - | - | - |
| Chrome | 他のタブをすべて閉じる | `Cmd+Ctrl+W` |

設定の手順:

1. `システム設定 → キーボード → キーボードショートカット… → アプリのショートカット` を開く
2. 「+」を押して、上の表のアプリ・メニュータイトル・キーを入力する
3. 対象のアプリを再起動する

メニュータイトルは、メニューバーに出ている文字と一字一句同じにする。アプリの表示言語が日本語以外のときは、その言語でのタイトルを入力する。

### 2-2. ウィンドウの分割

macOS 標準の、ウィンドウを画面の半分に置く機能のショートカットを変える。

| 機能 | キー | 初期設定 |
| - | - | - |
| ウィンドウを画面の左半分に置く | `Ctrl+Option+←` | `fn+Ctrl+←` |
| ウィンドウを画面の右半分に置く | `Ctrl+Option+→` | `fn+Ctrl+→` |

設定の手順:

1. `システム設定 → キーボード → キーボードショートカット… → ウインドウ` を開く
2. 左半分と右半分の項目のキーを、上の表のキーに変える

補足: `Ctrl+Option+↑` と `Ctrl+Option+↓` は macOS ではなく Raycast で設定している。

| キー | Raycast のコマンド |
| - | - |
| `Ctrl+Option+↑` | Center Three Fourths |
| `Ctrl+Option+↓` | Almost Maximize |

## 3. Tips

知っておくと便利な macOS のショートカット。

| キー | 動作 |
| - | - |
| `Ctrl+←` / `Ctrl+→` | 左 / 右の仮想デスクトップに切り替える |
| `Ctrl+1` 〜 `Ctrl+4` | その番号の仮想デスクトップに切り替える |
| `Ctrl+↑` | Mission Control を開く（開いているウィンドウをすべて並べて表示する） |
| `Ctrl+↓` | 今使っているアプリのウィンドウだけを並べて表示する |

`Ctrl+番号` は初期設定ではオフになっている。`システム設定 → キーボード → キーボードショートカット… → Mission Control` でオンにする。
