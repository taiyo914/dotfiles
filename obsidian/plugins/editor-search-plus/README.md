# Editor Search Plus

## 概要

編集ビュー (ライブプレビューとソースモード) のファイル内検索 (Cmd+F/cmd+option+F) を使いやすくするプラグイン

- 検索欄に入力すると、一致したすべての文字列をリアルタイムにハイライトする
- ハイライトは検索バーを閉じるまで消えない
- Enter で次へ、Shift+Enter で前へ進む
- 「すべて検索」ボタンは不要になるので隠す
- 検索バーの正規表現ボタンを追加。ONにすると JavaScript の正規表現で検索できる
- 正規表現が間違っているときは検索欄が赤くなり、ホバーするとエラーの内容が出る


読み取りビューの検索は、本体がもともとすべての一致をハイライトするので対象外。

## JavaScript 正規表現の使い方

Perl 正規表現との違いを簡単に紹介する。

- 大文字と小文字は区別する。区別しないときは先頭に `(?i)` を書く
- `^` と `$` は行の先頭と末尾に一致する。ファイル全体の先頭と末尾は `\A` `\z` `\Z`
- `.` は改行に一致しない。一致させるときは先頭に `(?s)` を書く
- Perl の書き方から変換して使えるもの: `\Q...\E`、`\x{263A}`、`\pL`、`\g1` `\g{name}`、`[[:alpha:]]` などの POSIX 文字クラス、`(?P<name>...)` `(?'name'...)` `(?P=name)`、`(?#コメント)`、`\#` のように記号の前に付けた `\`
- 使えないもの: アトミックグループ `(?>...)`、強欲な量指定子 `a++`、再帰 `(?R)`、`\K`、条件分岐、途中に書いた `(?i)`、`(?x)`

置換検索列では次のものを使える。

- `$1` `${1}` `\1`、`$&`、`${name}` `$+{name}`
- `\n` (改行)、`\t` (タブ)
- `\U` `\L` (`\E` まで大文字 / 小文字にする)、`\u` `\l` (次の 1 文字だけ大文字 / 小文字にする)

正規表現が OFF のときは本体と同じく、大文字と小文字を区別せずに文字列そのままで探し、置換文字列もそのまま入れる。
