## 概要

Bases の表示（ビュー）の切り替えを、ツールバーに横並びのタブで表示するプラグイン。Notion のデータベースのタブと同じように、1回のクリックで表示を切り替えられる。

## 使い方

- タブをクリックすると、その表示に切り替わる
- タブを右クリックすると、その表示の設定を開く
- タブの右の ⌃⌄ ボタンから、今までどおり「ビューを追加」などのメニューを開ける
- 画面の幅が狭くてタブが入りきらないときは、タブを隠して元のメニュー（表示名と ⌃⌄ のボタン）に戻る

## 注意

Bases の公開 API には表示を切り替える方法がないため、Obsidian 内部の仕組みを使っている。Obsidian の更新で内部の仕組みが変わると、タブが出なくなることがある。その場合も元のメニューはそのまま使える。
