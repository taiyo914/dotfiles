## 概要

`tasks/` フォルダのノートを1枚ずつのカードとして、Bases に次の3つの表示を追加するプラグイン。

- **Kanban**: status ごとの列にカードを並べる。終わっていない `blocked_by` があるカードは自動で BLOCKED 列に表示する
- **Dependencies**: `blocked_by` / `blocking` のつながりがあるカードだけを、先にやるカードから後でやるカードへ矢印でつないで表示する
- **Task table**: Obsidian 本体の表と同じく、ノートを1行ずつ並べる。行は中身に合わせて伸び、長い文字は必要な分だけ折り返す

絞り込み、並べ替え、検索、表示する列の選択は Bases の機能をそのまま使う。

### Task table でできること

- ファイル名をクリックすると、そのノートを開く
- status は、選択肢から選んで書き換えられる
- それ以外のプロパティ（blocked_by、blocking、date など）は、ノートのプロパティ欄と同じ入力欄でその場で書き換えられる。リンクの入力欄では `[[` と打つとノートの候補が出る
- 数式の列（ready? など）は計算した結果なので、書き換えられない
- 表の中で書き換えたものは、cmd + z で元に戻し、cmd + shift + z でやり直せる（入力欄に打ちかけの文字があるときは、その文字の取り消しになる）
- 列の見出しの右端をドラッグすると、列の幅を変えられる。幅は本体の表と同じく `.base` ファイルの `columnSize` に保存する

プロパティ欄の入力欄は Obsidian の公開 API ではない部品（`app.metadataTypeManager`）を使っている。Obsidian の更新で使えなくなったときは、値を表示するだけになる。

## 使い方

コマンド「Task Board: タスクボードを開く」で、vault 直下の `tasks.base` を開く。

- `tasks.base` が無いときは、このフォルダの `template.base`（ひな形）をコピーして作ってから開く
- 作った後の `tasks.base` は vault のファイルなので、列の幅や並べ替えを変えても dotfiles には差分が出ない
- ひな形を変えても、すでにある `tasks.base` には反映されない。反映したいときは `tasks.base` を消してからコマンドを実行する

自分で `.base` ファイルを作る場合は、絞り込みを `file.inFolder("tasks")` にして、表示の追加メニューから「Kanban」「Dependencies」「Task table」を選ぶ。

## カード（ノート）

- Kanban の列の下の「+ 新規ページ」、Bases のツールバーの「新規」、コマンド「Task Board: タスクを作成」のどれかで作る
  - ツールバーの「新規」は、task-board の表示（Kanban / Dependencies / Task table）を出しているときだけ、「+ 新規ページ」と同じ入力画面に置き換わる。status は TODO になる
- 作るときの画面では、タイトルと一緒に絵文字・`blocked_by`・`blocking` も入れられる
  - タイトルの左のボタンを押すと、絵文字を選ぶ画面（下の「絵文字を選ぶ」と同じ画面）が開く。「タイトルから検索」は、その時点で入力しているタイトルで探す
  - `blocked_by` / `blocking` の入力欄にカードのタイトルの一部を打つと、カードの候補が出る。何も打っていないときは、最近書き換えた終わっていないカードが出る
  - 選んだカードは入力欄の中に並ぶ。× を押すか、入力欄が空のときに Backspace を押すと外せる
  - タイトルの入力欄で Enter、どこでも cmd + Enter、「作成」ボタンのどれかで作る。相手のカードの逆側（`blocking` / `blocked_by`）も自動で書き足される
- `tasks/261108_タイトル.md` という名前で作られる。カードには先頭の日付を除いたタイトルだけを表示する
  - 同じ日に同じタイトルのカードを作ると、2枚目以降は `261108_タイトル 2.md` のように末尾に番号が付く
- カードをクリックするとボードの右側に開く。cmd + クリックで新しいタブに開く
- カード（Task table では行）を右クリックして「ステータスを変更」にマウスを乗せると status の一覧が開き、選んだ status に書き換わる。今の status には印が付く（Task table では cmd + z で戻せる）
- カード（Task table では行）を右クリックして「削除」を押すと、ノートを削除する。削除のしかたは Obsidian の「削除したファイル」の設定（ゴミ箱に移すなど）に従う
- カードを別の列にドラッグすると、status がその列の値になる
- カードを同じ列の中でドラッグすると、順番を入れ替えられる。順番は `order` プロパティに数字で保存する
  - 列の中は `order` の小さい順に並ぶ。`order` のないカード（作ったばかりのカードなど）は列の一番下に並ぶ
  - Kanban では Bases の並べ替えの設定より `order` を優先する
  - `order` はノートのプロパティ欄には表示しない（ソースモードでは見える）

- カードを右クリックして「絵文字を選ぶ」を押すか、Task table の name 列の絵文字を押すと、絵文字を選ぶ画面が開く。選んだ絵文字が `icon` に入る
  - 一覧には「入力した絵文字を使う」「入力した文字で検索」「タイトルから検索」「削除」がいつも出る。「削除」は付いている絵文字を外す
  - 開いた直後は先頭の「入力した絵文字を使う」を選んでいるので、絵文字を入力（貼り付け）して Enter を押すとその絵文字に決まる。絵文字1つ以外の文字のときは「絵文字を1つ入力してください」と赤字で出して止まる
  - 候補を探すと、入力した文字かタイトルに合う絵文字の候補を10個出す。一度出した候補は Obsidian を閉じるまで覚えておき、同じタイトルや同じ文字では探し直さない
  - 候補は zsh の `emoji` 関数（`dotfiles/zsh/rc/claude.zsh`、Claude に絵文字を挙げてもらう）で出す。数秒かかる
  - コマンドパレットの「Task Board: 開いているタスクの絵文字を選ぶ」でも使える
  - 候補は外部のコマンドで出すので、候補を探す項目はパソコンの Obsidian にだけ出る。スマホでは直接入力だけ使える

```yaml
---
status: TODO        # BLOCKED / TODO / WIP / DONE / ARCHIVE
icon: 🛒            # カードのタイトルの前に表示する。空のままでもよい
blocked_by:         # 先に終わらせる必要があるカード
  - "[[261108_作り方を調べる]]"
blocking: []        # このカードが終わるのを待っているカード
resume_cmd: []      # このタスクで使った Claude のセッションを開き直すコマンド（claude --resume ...）
session_cwd: []     # そのセッションを始めたディレクトリ
order: 1.5          # 列の中の順番。ドラッグで自動で書き換わる
---
```

## DONE と ARCHIVE

- DONE は最近終わったカードを置く列。Kanban に表示する
- ARCHIVE は片付け済みのカードの置き場所。Kanban ではカードを表示せず、枚数だけを表示する
  - カードを ARCHIVE 列にドラッグすると片付けられる
  - DONE 列の右上のボタンで、DONE のカードを全部 ARCHIVE に移せる
  - ノートは消えないので、TABLE で探したり、status を書き換えて元に戻したりできる

## 依存関係

- `blocked_by` と `blocking` は、片方を書き換えると相手のノートの逆側が自動で書き換わる
  - A の `blocked_by` に B を入れると、B の `blocking` に A が入る
  - つながっているノートを削除すると、相手のノートからそのリンクが消える
  - リンクはファイル名だけの形（`[[261108_作り方を調べる]]`）にそろえる。表示名付きのリンク（`[[ファイル名|タイトル]]`）を入れると、ファイル名だけの形に自動で書き直す
- DONE と ARCHIVE のカードは「終わったカード」として扱う
- `blocked_by` に終わっていないカードがあると、status が TODO や WIP のままでも BLOCKED 列に表示する。`blocked_by` のカードが全部終わると、status の列に戻る
- 依存カードがなくても、外部の都合で待っているカードは手で `status: BLOCKED` にできる
