## 概要

ファイルエクスプローラーのファイル・フォルダを、vault 直下の folder_order.md に書いた順番に並べるプラグイン。

## 使い方

folder_order.md に、並べたい順番でフォルダ名/ファイル名を書く。サブフォルダはインデントして書く。

```
templates
books
  */notes: desc
TODO.md
```

- 名前の後ろに `: asc` / `: desc` を付けると、そのフォルダの中で書いていないものが名前の昇順 / 降順で並ぶ
- `*` は `/` を含まない任意の文字列に一致する（例: `*/notes`、`*.pdf`、`*_moc.md`）
- `**` は何階層分でも任意のフォルダに一致する（例: `**/notes`）
