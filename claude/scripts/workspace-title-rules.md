herdr の space（workspace）に付ける名前のルール。
auto-title.sh（最初の質問で名前を付ける）と /retitle コマンド（名前を付け直す）の両方がこのファイルを読む。

名前は「テーマ:タスクの要約」の形にする。

テーマは、何の話かがわかる英小文字の短い略語（8 文字以内）にする。
次の表にある話題のときは、必ず表の略語を 1 文字も変えずにそのまま使う。

| 話題 | 略語 |
| Neovim | nvim |
| Ghostty | ghsty |
| Karabiner-Elements | kar |
| zsh | zsh |
| Claude Code | claude |
| herdr | herdr |
| Obsidian | obs |
| VS Code | vscode |
| Git | git |
| lazygit | lazygit |
| Keyball | keyball |
| ZMK | zmk |
| Chrome | chrome |
| macOS | mac |

表にない話題のときは、同じくらい短い略語を自分で作る。

タスクの要約は、何をしようとしているかを日本語で 20 文字以内にまとめたものにする。

例:
- ghostty でフォントを変えたい → ghsty:フォントの変更
- karabiner で caps を ctrl にしたい → kar:capsをctrlにする
