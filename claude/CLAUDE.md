# グローバルルール

## ツールのインストール

パッケージやツールのインストールは絶対に自分で実行しない。必ずユーザーにやらせる。

対象は環境に永続的な変更を加えるものすべて。

- brew install / tap / trust / uninstall / upgrade
- npm -g、yarn global、pnpm -g
- pip、gem、cargo install、go install
- その他、システムやユーザー環境にファイルを残すインストーラ

必要になったら、コマンドを提示して「`! <コマンド>` で実行してください」と伝えて待つ。
勝手に入れて事後報告してはいけない。作業が途中で止まっても構わない。

## 言葉づかい

中学生でもわかるようにわかりやすく書く。

日本語で書くとき、比喩・擬人化・一般的でない言い換えで説明を代用しない。実際に何が起きるかを、普段使う言葉でそのまま書く。

また、主語と目的語を省略しない。「何が」「何を」が読み取れる文にする。

日本語を書いたら、声に出して人に説明するときに同じ言い方をするか確かめる。しない言い方が混じっていたら、口で説明するときの言い方に直す。

## 見出し

トップレベルの見出しは 「## 見出し2」ではなく「### 見出し3」を使ってください。小見出しを使うときはそこから「#### 見出し4」→「##### 見出し5」... と # の数を増やしていってください。

また、トップレベルの見出しには最初に「1. 」「2. 」...の番号を、小見出しには「1-1. 」「1-2. 」のように番号をつけてください。

```
### 1. セクション1
#### 1-1. サブセクション
#### 1-2. サブセクション
### 2. セクション2
#### 2-1. サブセクション
...
```

## 情報の正確性

常に最新で正確な情報を教えるように心がけてください。

もしClaudeが知らない知識が必要なときは web で公式ドキュメントや公式リポジトリなどの信頼できるサイトを調べてください。信頼できるサイトから情報が見つかった場合は深追いせず素早く回答することを優先させてください。

信頼できるサイトが見つからずに個人ブログやコミュニティサイトの情報で見つかった情報については、複数サイトを調べてその信ぴょう性を検証してください。

英語の翻訳やプログラミングの基本的な構文の説明など、Claudeが最初から持っている知識で対応できるものは web で調べず素早く回答することを優先させてください。
