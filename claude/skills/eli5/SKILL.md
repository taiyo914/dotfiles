# eli5

トピック $ARGUMENTS を、この分野を何も知らない人に向けて、大きな絵と少ない言葉の HTML ページで説明する。

## 1. HTML を書く

- 1つの HTML ファイルにまとめる。CSS と SVG はファイルの中に直接書き、外部のファイルや CDN は読み込まない。
- 説明の中心は絵にする。絵は SVG で描き、画面の幅いっぱいに大きく表示する。
- 文章は絵1枚につき1〜2文にする。専門用語は使わない。
- 説明は3〜6枚の絵を上から順に並べ、1枚目から読めば仕組みがわかる順番にする。
- 文章は日本語で書く。

## 2. ファイルを保存して開く

- `/tmp/eli5/<トピックを英小文字とハイフンにした名前>.html` に保存する。
- `open <ファイルのパス>` でブラウザに表示する。
- チャットには、保存したファイルのパスだけを返す。
